Why Use sip-client?

Built for lightweight automation without the bloat of full softphone GUIs

Automated Audio Playback

Attach any standard .wav file. Once the remote party answers, audio streams seamlessly over RTP using standard G.711 $\mu$-law/A-law.

Auto-Hangup Support

Specify --hangup to immediately send a BYE and exit cleanly once your announcement file completes. Perfect for automated notification alerts.

Digest Authentication (MD5)

Securely register and dial through Asterisk, FreePBX, Kamailio, OpenSIPS, and commercial cloud VoIP providers using standard HTTP Digest Auth.

Inbound Auto-Answer Mode

Use sip-client listen to act as an automated announcement server or test audio loopback responder on port 5060.

Win32 Native Integration

Runs natively in Windows PowerShell, CMD, or as a Win32 console app with native dialog notifications (--win32).

Built-in Test WAV Generator

Need audio to test immediately? Run sip-client gen-wav test.wav to generate a clean 8kHz sine audio file in seconds.

Installation & Usage

Install directly from crates.io with one command

Install from crates.io:
cargo install sip-client
Dial and play an audio message:
sip-client call sip:1000@192.168.1.1 --play alert.wav --hangup
